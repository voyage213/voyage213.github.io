AIエージェントとその応用AI Agents and Applications

担当教員：黃芳誼、葉崇揚。2027年春学期、社会学部3年次の選択科目、3単位、定員60名。履修条件なし、プログラミングの基礎は不要です。

科目概要Course Description

本科目は、社会学の視点からAIエージェントの理論、ツール、応用を学びます。プログラミングの基礎は前提としません。理論面では大規模言語モデル、プロンプト・コンテキストエンジニアリング、ReActエージェントアーキテクチャ、RAG、MCP、マルチエージェントシステム、評価方法、情報セキュリティとガバナンスを扱います。実践面では各種AIエージェントツール（Claude Code、OpenAI Codex、Gemini CLI、Cursor、GitHub Copilot、Lovable、Bolt.new、v0、Replit Agent、n8nなど）を比較し、Vibe Codingでウェブサイト、アプリ、研究エージェントを制作します。社会科学への応用では、生成エージェントによる社会シミュレーション、LLMによる質的コーディング、AIが仕事、不平等、説明責任に与える影響を検討します。評価は隔週の課題、中間試験、期末試験、期末プロジェクト（理論分析と実装成果）で行います。ツール一覧は開講時のバージョンと無料プランに応じて更新します。

各週の要点Weekly Schedule

  1. W01

    導入：チャットボットからAIエージェントへ
    キーワード：AI Agent, Agentic AI, Rational Agent, PEAS, Autonomy, Human-in-the-Loop, Sociotechnical System
    実習：授業用ツール環境を整え、AIエージェントに複数ステップのタスクを実行させる。

  2. W02

    大規模言語モデルの原理
    キーワード：LLM, Foundation Model, Transformer, Attention, Token, Context Window, Embedding, Temperature, Hallucination
    実習：同じプロンプトで、モデルと温度による出力の違いを比較する。 課題1：モデル出力の比較とハルシネーションの検証

  3. W03

    プロンプトエンジニアリングとコンテキストエンジニアリング
    キーワード：System Prompt, Few-Shot, Chain-of-Thought, Structured Output (JSON), Prompt Engineering, Context Engineering
    実習：再利用できるシステムプロンプトと出力形式を作成する。 期末プロジェクトのグループ分け

  4. W04

    AIエージェントの基本アーキテクチャ
    キーワード：ReAct, Agent Loop, Tool Calling, Planning, Memory, Reflection, Orchestration
    実習：n8nで外部ツールを呼び出せる最初のエージェントを構築する。 課題2：n8nによるツール型エージェント

  5. W05

    知識検索とツールプロトコル
    キーワード：RAG, Vector Database, Chunking, Semantic Search, MCP, Agent Skills, A2A
    実習：社会政策文書からRAG質問応答エージェントを構築し、MCPサーバーに接続する。

  6. W06

    AIエージェントツールの概観と比較
    キーワード：Terminal agents (Claude Code, OpenAI Codex, Gemini CLI); IDE agents (Cursor, GitHub Copilot, Windsurf, Google Antigravity); cloud autonomous agents (Devin); app builders (Lovable, Bolt.new, v0, Replit Agent); workflows and frameworks (n8n, Dify, LangGraph, CrewAI, AutoGen)
    実習：グループで同じタスクを異なるツールで試し、コスト・速度・品質を記録する。 課題3：AIエージェントツール評価レポート

  7. W07

    Vibe Codingの理論と方法
    キーワード：Vibe Coding, Agentic Coding, Spec-Driven Development, PRD, AGENTS.md / CLAUDE.md, Git, Version Control, Code Review, Technical Debt
    実習：要件仕様を書き、コーディングエージェントに初版を作らせ、Gitで修正を管理する。

  8. W08

    AIエージェントの応用（1）：ウェブサイト制作
    キーワード：Frontend, HTML / CSS / JavaScript, React, Responsive Design, Supabase, Deployment (Vercel, GitHub Pages), API Key, Environment Variables
    実習：Vibe Codingで社会課題の情報サイトを完成させ、公開する。 課題4：社会課題ウェブサイトの公開

  9. W09

    中間試験 範囲：第1〜8週（専門用語、論述、実装の読解）

  10. W10

    AIエージェントの応用（2）：アプリ制作
    キーワード：PWA, React Native, Expo, Backend, REST API, Authentication, UX, Accessibility
    実習：Replit AgentやLovableなどでスマートフォンで動くアプリの試作品を作り、ユーザーテストを行う。 課題5：モバイルアプリ試作；期末プロジェクト企画書の提出

  11. W11

    マルチエージェントシステム
    キーワード：Multi-Agent Systems, Orchestrator-Worker, Role Assignment, Handoff, Shared State, Emergent Behavior, LangGraph, CrewAI
    実習：組織社会学の分業の概念を用いて、3つの役割が協働するエージェントを設計する。

  12. W12

    エージェントの評価と可観測性
    キーワード：Evals, Benchmark, SWE-bench, Golden Dataset, Trajectory, Observability, Guardrails, Validity and Reliability
    実習：自分のエージェントの評価データセットを作り、性能指標を算出する。 課題6：エージェント評価レポート

  13. W13

    生成エージェントと社会シミュレーション
    キーワード：Generative Agents, Agent-Based Modeling, Silicon Sampling, Algorithmic Fidelity, Synthetic Respondents, External Validity, WEIRD Bias
    実習：台湾の世論調査項目をシミュレーションし、実際の調査結果と比較する。

  14. W14

    社会調査アシスタントとしてのAIエージェント
    キーワード：Computational Social Science, Research Workflow Automation, Codebook to Promptbook, LLM Annotation, Cohen's Kappa, Research Ethics
    実習：エージェントでインタビューやニュースのテキストをコーディングし、人手のコーディングとの一致度を比較する。 課題7：LLMコーディングと人手コーディングの比較

  15. W15

    AIエージェント、仕事、社会的不平等
    キーワード：Task-Based Approach, Automation vs. Augmentation, Deskilling, Productivity Paradox, Digital Divide, Algorithmic Management
    実習：台湾のある職業のタスクを分析し、エージェントに代替・増強されうる部分を評価する。

  16. W16

    安全、倫理、ガバナンス
    キーワード：Prompt Injection, Least Privilege, Sandbox, Data Leakage, Red Teaming, Moral Crumple Zone, Accountability, Taiwan's AI Basic Act, EU AI Act
    実習：期末プロジェクトにレッドチーミングを行い、個人情報と権限を点検する。 課題8：プロジェクトの安全・倫理チェック

  17. W17

    期末プロジェクト成果発表（Demo Day）
    キーワード：Proof of Concept, MVP, Peer Review
    実習：各グループがエージェント、ウェブサイト、アプリを実演し、社会学的根拠と評価結果を説明する。 期末プロジェクト発表

  18. W18

    期末試験 範囲：第10〜16週；期末プロジェクトの報告書と作品リンクの提出
