AI 에이전트와 응용AI Agents and Applications

담당 교수: 黃芳誼, 葉崇揚. 2027년 봄학기, 사회학과 3학년 선택 과목, 3학점, 정원 60명. 선수 과목이 없으며 프로그래밍 기초가 필요하지 않습니다.

교과목 소개Course Description

이 과목은 사회학적 관점에서 AI 에이전트의 이론, 도구, 응용을 다루며 프로그래밍 기초를 전제하지 않습니다. 이론 부분은 대규모 언어 모델, 프롬프트·컨텍스트 엔지니어링, ReAct 에이전트 구조, RAG, MCP, 멀티 에이전트 시스템, 평가 방법, 정보 보안과 거버넌스를 포함합니다. 실습 부분은 다양한 AI 에이전트 도구(Claude Code, OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot, Lovable, Bolt.new, v0, Replit Agent, n8n 등)를 비교하고 Vibe Coding으로 웹사이트, 앱, 연구 에이전트를 제작합니다. 사회과학 응용 부분은 생성 에이전트 사회 시뮬레이션, LLM 질적 코딩, AI가 노동, 불평등, 책임성에 미치는 영향을 탐구합니다. 평가는 격주 과제, 중간고사, 기말고사, 기말 프로젝트(이론 분석과 실제 결과물)로 이루어집니다. 도구 목록은 개설 시점의 버전과 무료 요금제에 따라 갱신됩니다.

주차별 핵심Weekly Schedule

  1. W01

    도입: 챗봇에서 AI 에이전트로
    핵심 용어: AI Agent, Agentic AI, Rational Agent, PEAS, Autonomy, Human-in-the-Loop, Sociotechnical System
    실습: 수업 도구 환경을 구축하고 AI 에이전트로 여러 단계의 과제를 수행한다.

  2. W02

    대규모 언어 모델의 원리
    핵심 용어: LLM, Foundation Model, Transformer, Attention, Token, Context Window, Embedding, Temperature, Hallucination
    실습: 같은 프롬프트로 모델과 온도에 따른 출력 차이를 비교한다. 과제 1: 모델 출력 비교와 할루시네이션 검증

  3. W03

    프롬프트 엔지니어링과 컨텍스트 엔지니어링
    핵심 용어: System Prompt, Few-Shot, Chain-of-Thought, Structured Output (JSON), Prompt Engineering, Context Engineering
    실습: 재사용 가능한 시스템 프롬프트와 출력 형식을 작성한다. 기말 프로젝트 조 편성

  4. W04

    AI 에이전트의 핵심 구조
    핵심 용어: ReAct, Agent Loop, Tool Calling, Planning, Memory, Reflection, Orchestration
    실습: n8n으로 외부 도구를 호출할 수 있는 첫 에이전트를 구축한다. 과제 2: n8n 도구형 에이전트

  5. W05

    지식 검색과 도구 프로토콜
    핵심 용어: RAG, Vector Database, Chunking, Semantic Search, MCP, Agent Skills, A2A
    실습: 사회정책 문서로 RAG 질의응답 에이전트를 만들고 MCP 서버를 연결한다.

  6. W06

    AI 에이전트 도구 개관과 비교
    핵심 용어: Terminal agents (Claude Code, OpenAI Codex, Gemini CLI); IDE agents (Cursor, GitHub Copilot, Windsurf, Google Antigravity); cloud autonomous agents (Devin); app builders (Lovable, Bolt.new, v0, Replit Agent); workflows and frameworks (n8n, Dify, LangGraph, CrewAI, AutoGen)
    실습: 조별로 같은 과제를 서로 다른 도구로 시도하고 비용, 속도, 품질을 기록한다. 과제 3: AI 에이전트 도구 평가 보고서

  7. W07

    Vibe Coding의 이론과 방법
    핵심 용어: Vibe Coding, Agentic Coding, Spec-Driven Development, PRD, AGENTS.md / CLAUDE.md, Git, Version Control, Code Review, Technical Debt
    실습: 요구사항 명세를 작성해 코딩 에이전트로 첫 버전을 만들고 Git으로 수정을 관리한다.

  8. W08

    AI 에이전트 응용 (1): 웹사이트 제작
    핵심 용어: Frontend, HTML / CSS / JavaScript, React, Responsive Design, Supabase, Deployment (Vercel, GitHub Pages), API Key, Environment Variables
    실습: Vibe Coding으로 사회 문제 정보 웹사이트를 완성해 공개 배포한다. 과제 4: 사회 문제 웹사이트 공개

  9. W09

    중간고사 범위: 1~8주 (전문 용어, 논술, 실습 판독)

  10. W10

    AI 에이전트 응용 (2): 앱 제작
    핵심 용어: PWA, React Native, Expo, Backend, REST API, Authentication, UX, Accessibility
    실습: Replit Agent나 Lovable 등의 도구로 휴대폰에서 작동하는 앱 시제품을 만들고 사용자 테스트를 진행한다. 과제 5: 모바일 앱 시제품; 기말 프로젝트 기획서 제출

  11. W11

    멀티 에이전트 시스템
    핵심 용어: Multi-Agent Systems, Orchestrator-Worker, Role Assignment, Handoff, Shared State, Emergent Behavior, LangGraph, CrewAI
    실습: 조직사회학의 분업 개념을 활용해 세 가지 역할이 협업하는 에이전트를 설계한다.

  12. W12

    에이전트 평가와 관측 가능성
    핵심 용어: Evals, Benchmark, SWE-bench, Golden Dataset, Trajectory, Observability, Guardrails, Validity and Reliability
    실습: 자신의 에이전트를 위한 평가 데이터셋을 만들고 성능 지표를 계산한다. 과제 6: 에이전트 평가 보고서

  13. W13

    생성 에이전트와 사회 시뮬레이션
    핵심 용어: Generative Agents, Agent-Based Modeling, Silicon Sampling, Algorithmic Fidelity, Synthetic Respondents, External Validity, WEIRD Bias
    실습: 대만의 여론 조사 문항을 시뮬레이션하고 실제 조사 결과와 비교한다.

  14. W14

    사회 연구 조수로서의 AI 에이전트
    핵심 용어: Computational Social Science, Research Workflow Automation, Codebook to Promptbook, LLM Annotation, Cohen's Kappa, Research Ethics
    실습: 에이전트로 인터뷰나 뉴스 텍스트를 코딩하고 사람의 코딩과 일치도를 비교한다. 과제 7: LLM 코딩과 사람 코딩 비교

  15. W15

    AI 에이전트, 노동, 사회 불평등
    핵심 용어: Task-Based Approach, Automation vs. Augmentation, Deskilling, Productivity Paradox, Digital Divide, Algorithmic Management
    실습: 대만의 한 직업의 과업을 분석해 에이전트가 대체하거나 증강할 수 있는 부분을 평가한다.

  16. W16

    보안, 윤리, 거버넌스
    핵심 용어: Prompt Injection, Least Privilege, Sandbox, Data Leakage, Red Teaming, Moral Crumple Zone, Accountability, Taiwan's AI Basic Act, EU AI Act
    실습: 기말 프로젝트에 레드팀 점검을 실시하고 개인정보와 권한을 확인한다. 과제 8: 프로젝트 보안·윤리 점검

  17. W17

    기말 프로젝트 발표 (Demo Day)
    핵심 용어: Proof of Concept, MVP, Peer Review
    실습: 각 조가 에이전트, 웹사이트 또는 앱을 시연하고 사회학적 근거와 평가 결과를 설명한다. 기말 프로젝트 발표

  18. W18

    기말고사 범위: 10~16주; 기말 프로젝트 보고서와 작품 링크 제출
